# 内覧会（2026年11月6日）案内資料

いやしのおうち 内覧会の「案内文（関係業者向け・A4）」と「告知フライヤー（A5両面）」です。

## ファイル

| ファイル | 用途 | 形式 |
|---|---|---|
| `invitation-a4.docx` | 関係業者向け 案内文 | Word（A4・1枚） |
| `generate_invitation_docx.py` | 上記Wordを生成するスクリプト | Python |
| `flyer-a5.html` | 告知フライヤー | HTML（A5・両面＝2ページ） |
| `qr-site.png` | 公式サイトのQRコード（フライヤー裏面で使用） | PNG |

## 案内文（Word）の編集・再生成

- `invitation-a4.docx` を Word で開いてそのまま編集できます。
- 本文や日時をまとめて直したいときは、`generate_invitation_docx.py` を編集して再生成します。

```bash
pip install python-docx
python3 generate_invitation_docx.py   # invitation-a4.docx を出力
```

- フォントは本文＝游明朝、見出し＝游ゴシック（Windowsの標準フォント）。
  未インストールの環境では自動で別フォントに置き換わります。

## フライヤー（HTML）の印刷・PDF化

1. `flyer-a5.html` をブラウザ（Chrome推奨）で開く
2. 印刷 → 用紙サイズ **A5**、余白 **なし**、背景のグラフィックを**有効**にする
3. 「PDFに保存」で2ページ（表・裏）のPDFになります
4. 両面印刷すると A5 両面フライヤーになります
